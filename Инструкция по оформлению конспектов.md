# Инструкция по оформлению конспектов

Шаблоны: [[_Шаблоны/Определение|Определение]] · [[_Шаблоны/Теорема|Теорема]] · [[_Шаблоны/Утверждение|Утверждение]].
Пример готовой заметки: [[Def. Линейная связность]].

## 1. Разовая настройка
- Плагин **Шаблоны** включён, папка шаблонов — `_Шаблоны`.
- Настройки → Оформление → CSS-фрагменты → ⟳ → включить **konspekt-callouts**. Без него все блоки выглядят одинаково.
- Удобно: Настройки → Горячие клавиши → «Шаблоны: Вставить шаблон» → например `Cmd+T`.

## 2. Как создать заметку
| Что пишем    | Имя файла              | Шаблон        | Цвет      |
| ------------ | ---------------------- | ------------- | --------- |
| Определение  | `Def. Название`        | Определение   | голубой   |
| Теорема      | `Th. Название`         | Теорема       | золотой   |
| Утверждение, лемма | `Prop. Название` | Утверждение   | бирюзовый |

1. Создайте заметку в папке темы: `Предмет/семестр/Курс/Тема/`.
2. Назовите её по таблице: префикс нужен для цвета в графе.
3. `Cmd+P` → «Шаблоны: Вставить шаблон» → нужный шаблон.
4. Заголовок подставится из имени файла.

## 3. Как заполнять
- Свойства: `лекция` — номер лекции, `статус` — `черновик` → `готово`.
- Ненужные разделы удаляйте.
- Доказательство (`> [!proof]-`) свёрнуто по умолчанию, знак ∎ ставится сам.
- Для леммы или следствия измените заголовок блока: `> [!proposition] Лемма`, `> [!theorem] Следствие`.
- В разделе «Связи» ставьте ссылки `[[...]]`: из них строится граф.

## 4. Формулы
- **Текст — вне формул**, формула — в `$...$` (в строке) или `$$...$$` (отдельно).
  - ❌ `$$Метрическое\ пространство\ (X,d)\ связно$$`
  - ✅ `Метрическое пространство $(X, d)$ связно, если …`
- Внутри блока каждую строку, и формулы тоже, начинайте с `> `.
- Слово внутри формулы: `\text{...}`.
- Греческие буквы командами (`\gamma`), а не символами (`γ`).

## 5. Блоки
| Блок                   | Для чего                              |
| ---------------------- | ------------------------------------- |
| `> [!definition]`      | определение                           |
| `> [!theorem]`         | теорема, следствие                    |
| `> [!proposition]`     | утверждение, лемма                    |
| `> [!proof]-`          | доказательство                        |
| `> [!info] Обозначения`| обозначения                           |
| `> [!example]`         | пример                                |
| `> [!failure]`         | контрпример                           |

## 6. Граф
Граф (`Cmd+G`) строится по ссылкам `[[...]]`. Цвет вершины задают **группы**: шестерёнка в графе → **Группы** → «Новая группа» → запрос + цвет. Если подходят несколько групп, побеждает первая.

Настроено: `file:"Def."` — голубой, `file:"Th."` — золотой, `file:"Prop."` — бирюзовый. Шаблоны и эта инструкция скрыты фильтром `-path:"_Шаблоны" -file:"Инструкция"`.

Другие запросы: по курсу `path:"Математически анализ"`, по теме `path:"Связность"`, черновики `["статус":черновик]`. Связи одной заметки — Cmd+P → «Граф: открыть локальный граф».
