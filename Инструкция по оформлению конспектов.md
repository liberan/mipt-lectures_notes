# Инструкция по оформлению конспектов

Шаблон: [[_Шаблоны/Конспект|Конспект]]. Пример готовой заметки: [[Def. Линейная связность]].

## 1. Разовая настройка (уже сделано)
- Плагин **Шаблоны** (Templates) включён, папка шаблонов — `_Шаблоны` (`.obsidian/templates.json`).
- CSS-сниппет `konspekt-callouts`: Настройки → Оформление → CSS-фрагменты → кнопка «обновить» ⟳ → переключатель **konspekt-callouts** включён. Без него все блоки выглядят одинаково.
- Если что-то не работает — перезапустите Obsidian.

## 2. Как создать конспект
1. Создайте заметку в нужной папке: `Предмет/семестр/Курс/Тема/`.
2. Назовите её по схеме:
   - `Def. Название` — определение,
   - `Th. Название` — теорема / лемма / утверждение,
   - `Название` — обзорная заметка по теме.
3. `Ctrl/Cmd + P` → «Шаблоны: Вставить шаблон» → **Конспект**.
   (Удобно назначить горячую клавишу: Настройки → Горячие клавиши → «Вставить шаблон».)
4. Заголовок подставится сам (из имени файла).

## 3. Как заполнять
**Свойства (шапка):**
- `лекция` — номер лекции (если нужен).
- `статус` — `черновик` → `готово`.

Предмет, тему и связи между заметками задают **папки и ссылки** `[[...]]`, а не свойства.

**Тело заметки:**
- Ненужные блоки **удаляйте**. В определении обычно нет «Теоремы» и «Доказательства», а в теореме нет «Определения».
- `[!proof]-` с минусом сворачивается по умолчанию, это удобно при повторении.
- В разделе «Связи» ставьте ссылки `[[...]]` на другие заметки. Так строится граф курса.

## 4. Правила записи формул
- **Текст пишите вне формул**, а формулу — внутри `$...$` (в строке) или `$$...$$` (отдельно).
  - ❌ `$$Метрическое\ пространство\ (X,d)\ связно$$`
  - ✅ `Метрическое пространство $(X, d)$ связно, если …`
- Внутри блока (`> [!definition]`) каждую строку формулы тоже начинайте с `> `.
- Если в формуле всё же нужно слово, используйте `\text{...}`: `$\gamma \text{ непрерывна}$`.
- Кванторы и стандартные обозначения: `\forall`, `\exists`, `\in`, `\subset`, `\mathbb{R}`, `\gamma`. Не вставляйте греческие буквы символами (`γ`), пишите командами.
- Большие скобки: `\big( … \big)` или `\left( … \right)`.

## 5. Типы блоков (callouts)
| Блок                | Для чего                          |
| ------------------- | --------------------------------- |
| `> [!definition]`   | определение                       |
| `> [!theorem]`      | теорема, лемма, утверждение       |
| `> [!proof]-`       | доказательство (свёрнуто)         |
| `> [!info]`         | обозначения                       |
| `> [!example]`      | пример                            |
| `> [!failure]`      | контрпример                       |
| `> [!warning]`      | типичная ошибка, тонкое место      |

## 6. Граф и группы вершин
Граф (`Cmd+G`) строится по ссылкам `[[...]]`. Цвета вершин задаются **группами**: значок шестерёнки в графе → **Группы** → «Новая группа» → запрос + цвет. Первая подходящая группа побеждает.

Уже настроено (цвета совпадают с блоками):
| Запрос          | Цвет       | Что красит        |
| --------------- | ---------- | ----------------- |
| `file:"Def."`   | синий      | определения       |
| `file:"Th."`    | фиолетовый | теоремы           |
| `file:"Lem."`   | оранжевый  | леммы             |

В фильтре графа скрыты шаблоны и эта инструкция: `-path:"_Шаблоны" -file:"Инструкция"`.

Другие полезные запросы:
- по курсу: `path:"Математически анализ"`;
- по теме: `path:"Связность"`;
- черновики: `["статус":черновик]`.

Чтобы смотреть один курс, впишите `path:"…"` в поле «Фильтр» графа или откройте **локальный граф** заметки (Cmd+P → «Граф: открыть локальный граф»).
