# Инструкция по оформлению конспектов

Шаблоны (на английском): [[_Templates/Definition|Definition]] · [[_Templates/Theorem|Theorem]] · [[_Templates/Lemma|Lemma]] · [[_Templates/Proposition|Proposition]].
Пример готовой заметки: [[Def. Линейная связность]].

## 1. Разовая настройка
- Плагин **Шаблоны** включён, папка шаблонов — `_Templates`.
- Настройки → Оформление → CSS-фрагменты → ⟳ → включить **konspekt-callouts**. Без него все блоки выглядят одинаково.
- Удобно: Настройки → Горячие клавиши → «Шаблоны: Вставить шаблон» → например `Cmd+T`.

## 2. Как создать заметку
| Что пишем    | Имя файла              | Шаблон        | Цвет      |
| ------------ | ---------------------- | ------------- | --------- |
| Определение  | `Def. Название`        | Definition    | синий     |
| Теорема      | `Th. Название`         | Theorem       | красный   |
| Лемма        | `Lem. Название`        | Lemma         | жёлтый    |
| Утверждение  | `Prop. Название`       | Proposition   | бирюзовый |

1. Создайте заметку в папке темы: `Предмет/семестр/Курс/Тема/`.
2. Назовите её по таблице: префикс нужен для цвета в графе.
3. `Cmd+P` → «Шаблоны: Вставить шаблон» → нужный шаблон.
4. Заголовок подставится из имени файла.

## 3. Как заполнять
- Свойства: `lecture` — номер лекции, `status` — `draft` → `done`.
- Ненужные разделы удаляйте.
- Доказательство (`> [!proof]- Proof`) свёрнуто по умолчанию, □ в начале и ■ в конце ставятся сами.
- Для следствия измените заголовок блока: `> [!theorem] Corollary`.
- В разделе «Связи» ставьте ссылки `[[...]]`: из них строится граф.

## 4. Формулы
- **Текст — вне формул**, формула — в `$...$` (в строке) или `$$...$$` (отдельно).
  - ❌ `$$Метрическое\ пространство\ (X,d)\ связно$$`
  - ✅ `Метрическое пространство $(X, d)$ связно, если …`
- Внутри блока каждую строку, и формулы тоже, начинайте с `> `.
- Слово внутри формулы: `\text{...}`.
- Греческие буквы командами (`\gamma`), а не символами (`γ`).

## 5. Блоки
| Блок                   | Для чего                              |
| ---------------------- | ------------------------------------- |
| `> [!definition]`      | определение                           |
| `> [!theorem]`         | теорема, следствие                    |
| `> [!lemma]`           | лемма                                 |
| `> [!proposition]`     | утверждение                           |
| `> [!proof]-`          | доказательство                        |
| `> [!info] Notation`   | обозначения                           |
| `> [!example]`         | пример (светло-голубой)               |
| `> [!failure]`         | контрпример (светло-жёлтый)           |

## 6. Граф
Граф (`Cmd+G`) строится по ссылкам `[[...]]`. Цвет вершины задают **группы**: шестерёнка в графе → **Группы** → «Новая группа» → запрос + цвет. Если подходят несколько групп, побеждает первая.

Настроено: `file:"Def."` — синий, `file:"Th."` — красный, `file:"Lem."` — жёлтый, `file:"Prop."` — бирюзовый. Шаблоны и эта инструкция скрыты фильтром `-path:"_Templates" -file:"Инструкция"`.

Другие запросы: по курсу `path:"Математически анализ"`, по теме `path:"Связность"`, черновики `["status":draft]`. Связи одной заметки — Cmd+P → «Граф: открыть локальный граф».
